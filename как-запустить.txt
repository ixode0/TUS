=== Вариант А — готовый бинарь из GitHub Releases (конфиг в ~/.config/tus) ===
1. Новичок (без Go): поставь готовый бинарь из GitHub Releases — install.sh сам скачает sniper
   под твою платформу (linux/darwin amd64+arm64, Windows — install.ps1) и проверит SHA256SUMS.
   Запуск: curl -fsSL https://raw.githubusercontent.com/ixode0/TUS/main/install.sh | bash
2. API ID и API Hash возьми на https://my.telegram.org → API development tools.
3. Конфиг лежит в ~/.config/tus/config.json (пути CONFIG_PATH/SESSION_PATH задаёт лаунчер tus).
   Телефон пиши с + (например +1234567890), юзернеймы без @ (например dead,devious).
4. Запуск: tus; при первом запуске введи код из Telegram. Если включена 2FA — на запрос
   Enter your password: введи пароль (ввод скрыт).
   Windows: бинарь sniper.exe, конфиг %LOCALAPPDATA%\TUS\config.json (ставит install.ps1); запуск: sniper.exe.

=== Вариант Б — запуск из исходников (конфиг рядом с кодом/бинарём) ===
5. Из исходников: cp config.example.json config.json и заполни api_id/api_hash/phone/usernames —
   тут config.json лежит рядом с кодом/бинарём (а не в ~/.config/tus).
6. Запуск: go run ./cmd/app или go build -o sniper ./cmd/app && ./sniper; при первом запуске
   введи код из Telegram, при 2FA — пароль на Enter your password: (ввод скрыт).
7. Успех — строка Successfully claimed: <username>; файл session_DO_NOT_SHARE.json никому
   не показывай и не коммить.
